# 🎓 Campus Event & Club Hub

A responsive university event and student club management platform built with **HTML, CSS, and JavaScript**. The platform helps students discover campus events, explore student clubs, and register for activities.

## 📌 About the Project

Campus Event & Club Hub is designed to provide university students with a single platform to discover and participate in campus activities.

Students can browse upcoming events, search and filter events, explore different student clubs, view event and club details, and register for events.

This project is currently being developed as a frontend application and is planned to be extended with a Java backend and MySQL database in future versions.

## ✨ Features

### 🏠 Home Page

* Modern and responsive landing page
* Featured campus events
* Popular student clubs
* Quick navigation to events and clubs
* Campus activity statistics

### 📅 Events

* Browse upcoming campus events
* Search events
* Filter events by category
* View event details
* View date, time, location, and available seats
* Register for events

### 👥 Student Clubs

* Explore university clubs
* Search clubs
* Filter clubs by category
* View club information
* View club activities
* Join clubs

### 📝 Event Registration

* Student registration form
* Form validation
* Event selection
* Registration confirmation
* Registration data stored using browser LocalStorage

### 📊 Student Dashboard

* View registered events
* View joined clubs
* View upcoming activities
* View registration history
* Cancel event registrations

## 🛠️ Technologies Used

* **HTML5** — Web page structure
* **CSS3** — Styling and responsive design
* **JavaScript** — Dynamic functionality and user interactions
* **LocalStorage** — Temporary client-side data storage

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/Harshith709/Campus-Event-Club-Hub.git
```

2. Open the project folder in **Visual Studio Code**.

3. Install the **Live Server** extension in VS Code.

4. Right-click `index.html`.

5. Select **Open with Live Server**.

6. The application will open in your web browser.
